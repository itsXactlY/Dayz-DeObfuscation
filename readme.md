## Overview

This collection contains tools and scripts designed to **analyze and de-obfuscate DayZ executables and scripts**, particularly focusing on common obfuscation techniques used in the community. Examples include reversing **LBMaster’s key encryption** and other trivial obfuscation methods.

## Features

- **de-obfuscation helpers** for common DayZ protections.
- Analysis scripts to study **key encryption and encoding schemes**.
- Tools to inspect, debug, and **reverse engineer DayZ heavily obfuscated scripts**.
- Educational examples demonstrating **how obfuscation works**.
